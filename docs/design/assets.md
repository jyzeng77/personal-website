## Original graphics

- Project artwork: inline SVG/CSS illustrations in `ProjectArtwork.tsx` and its stylesheet. These are decorative interpretations, not screenshots of the actual applications or evidence of results.
- Icons, cat doodle, and favicon: original simple SVG marks in the repository.
- Typography: local system-font stack; no external font requests or bundled font licenses.

## Future images

Keep personal photos separate from research screenshots. Add a source, photographer, permission/license, and alt-text description before publishing a new image. Preserve the original Pinterest reference provenance even if those files are reorganized.
