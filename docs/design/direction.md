# Current direction

Updated 2026-11-05. This file records Jerry's current choices. The [creative brief](creative-brief.md) preserves the earlier discussion and its changes; the [gallery](../reference-gallery.md) contains all original visual references.

## Confirmed

- Prefer the leftmost **Interface Collage (A)** and rightmost **Personal Archive (C)** generated concepts. A combination is likely; neither is the winner yet.
- Build both variations so they can be compared and mixed later.
- Use reusable components and editable content, with layouts kept separate.
- React + TypeScript + Vite, with normal CSS. Use CSS Modules to scope component styles and CSS variables for shared visual values.
- Keep code understandable to someone who has dabbled in JavaScript. Favour clear names and simple types.
- Keep the existing website on `main` while the two concepts develop on branches.
- Portfolio first: visible work, résumé, and contact; personal warmth and optional discoveries alongside them.

## Still exploratory

- Exact palette, typography, final arrangement, photos, decorative details, and amount of interface chrome.
- Final project ordering, case-study copy, and Jerry's personal contribution to team projects.
- The prototype uses sourced atmosphere photos, not Jerry's personal photographs.
- A recruiter mode, CMS, blog, backend, and a literal desktop UI are not approved requirements.

## How the prototypes interpret the concepts

- **Interface Collage:** a large readable introduction, overlapping software-inspired panels, clear featured work, and quiet photographic fragments.
- **Personal Archive:** a warm grid-paper canvas, folder-like navigation, varied paper surfaces, collected images, and restrained ephemera.
- Both share project data, project cards/dialogs, photos, music shelf, navigation, about content, and contact links.

The visual studies in the mockup are a starting point, not a pixel-perfect implementation contract. Do not turn the site into a fake operating system or hide work behind playful interactions.
